A simple AI-based system that analyzes resumes to extract key details, identify skills, and recommend job roles using Machine Learning and NLP.

⸻

Features
	•	Extracts name, email, and contact
	•	Detects skills from resume
	•	Classifies industry
	•	Recommends job roles

⸻

Tech Stack
	•	Python
	•	Machine Learning
	•	NLP
	•	Flask

⸻

How to Run
git clone https://github.com/your-username/your-repo-name.git
cd your-repo-name
pip install -r requirements.txt
python app.py

Usage
	•	Upload a resume
	•	Get extracted details, skills, and job recommendations
